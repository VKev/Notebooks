## Definition
- `Texture` là image data được Unity dùng khi render mesh, sprite, UI, material, shader effect, hoặc render target.
- Theo tài liệu Unity `6.4 (6000.4)`, Texture Import Settings quyết định Unity import file ảnh trong `Assets` thành texture asset như thế nào.
- Setting như texture type, sRGB, alpha, mipmap, compression, wrap mode, filter mode, và platform override ảnh hưởng trực tiếp tới chất lượng hình ảnh, memory, build size, và performance.
