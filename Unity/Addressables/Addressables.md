Folder này chứa kiến thức về `Addressables` trong Unity.
Nó tập trung vào package `com.unity.addressables` version `2.10`, giải thích cách quản lý asset theo địa chỉ thay vì reference trực tiếp, hỗ trợ load async, quản lý memory qua ref-counting, và phân phối content từ xa.
