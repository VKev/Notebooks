## Definition
- `Addressables` là hệ thống quản lý asset trong Unity cho phép load asset theo địa chỉ thay vì dùng direct reference hay đường dẫn cứng, tự động xử lý dependency và hỗ trợ load bất đồng bộ.
- Theo tài liệu package `com.unity.addressables` version `2.10`, Addressables thay thế cả `Resources` folder và `AssetBundle` thủ công bằng một API thống nhất, hỗ trợ cả local và remote content distribution.
