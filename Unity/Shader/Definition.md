## Definition
- `Shader` là chương trình chạy trên GPU để quyết định cách mesh, sprite, UI, hoặc full-screen effect được vẽ ra màn hình.
- Theo tài liệu Unity `6.3 LTS (6000.3)`, `Shader` object là container Unity-specific bọc một hoặc nhiều shader program, GPU instruction, `Properties`, `SubShader`, `Pass`, tag, fallback, và thông tin để Unity biết cách dùng shader đó với material.
- Trong Unity hiện đại, shader viết tay dùng `ShaderLab` để mô tả cấu trúc và `HLSL` để viết code chạy trên GPU.
