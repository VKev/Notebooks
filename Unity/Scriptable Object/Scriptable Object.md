Folder này chứa kiến thức về `Scriptable Object` trong Unity.
Nó tập trung vào tài liệu Unity `6.3 LTS (6000.3)`, giải thích cách tạo, quản lý, và ứng dụng `ScriptableObject` để tách data khỏi logic và xây dựng kiến trúc modular trong game.
