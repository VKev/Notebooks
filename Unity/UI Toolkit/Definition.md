## What is it
- `UI Toolkit` là hệ thống UI hiện đại trong Unity, lấy cảm hứng từ web development với mô hình tách biệt cấu trúc (`UXML`), style (`USS`), và logic (C#).
- Theo tài liệu Unity `6.3`, UI Toolkit hỗ trợ cả Editor UI và runtime UI, dùng `VisualElement` làm building block cơ bản và layout bằng flexbox, thay thế dần `UGUI` canvas-based truyền thống.
