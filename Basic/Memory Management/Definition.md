## What is it
- `Memory Management` trong C# là cách CLR tự động quản lý việc cấp phát và thu hồi bộ nhớ cho application thông qua `Stack`, `Heap`, và `Garbage Collector`.
- Hiểu memory management giúp viết code hiệu quả hơn, tránh memory leak, giảm GC pressure, và tránh các lỗi phổ biến như boxing không cần thiết hay giữ reference tới object đã chết.
